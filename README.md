# MomAI Code

O MomAI Code deixa o assistente trabalhar no seu código. Ele roda comandos no terminal, lê e edita arquivos e fica dentro da pasta do projeto que você autorizou.

## O que você pode fazer

- Rodar comandos dentro da pasta do projeto no Windows (PowerShell ou Prompt de Comando) e no Linux ou macOS (Bash).
- Trabalhar só nos projetos que você autorizou. Sem um projeto liberado, a MomAI fica na sua pasta pessoal. Se uma pasta ainda não estiver liberada, ela pede no chat.
- Bloquear comandos perigosos, como apagar pastas inteiras, formatar discos ou resetar o Git. Quando precisar de um comando, você libera uma vez ou libera sempre.
- Ler arquivos por trechos numerados, fazer trocas pontuais, criar arquivos e buscar no projeto inteiro.
- Desfazer as alterações junto com a mensagem do chat que as criou.
- Levar imagens e documentos do chat para a pasta do projeto sem mover arquivos na mão.

## Exemplos

- "Liste os arquivos do projeto MomAI e veja o que mudou no package.json."
- "Corrija o import quebrado em src/index.ts."
- "Rode os testes e me diga quais falharam."
- "Coloque a imagem que anexei em src/assets."
- "Vamos trabalhar na pasta D:\MeuSite."

## Permissões

- **Terminal:** para compilar, rodar testes, usar Git e executar scripts no seu computador.
- **Arquivos (leitura e escrita):** para ler o código, salvar edições e criar arquivos nos projetos autorizados.
