# MomAI Code

MomAI Code lascia che l'assistente lavori sul tuo codice. Esegue comandi nel terminale, legge e modifica file e resta nella cartella del progetto che hai autorizzato.

## Cosa puoi fare

- Eseguire comandi dentro la cartella del progetto su Windows (PowerShell o Prompt dei comandi) e su Linux o macOS (Bash).
- Lavorare solo nei progetti che hai autorizzato. Senza un progetto autorizzato, MomAI resta nella tua cartella personale. Se una cartella non è ancora permessa, la chiede nella chat.
- Fermare i comandi pericolosi, come cancellare intere cartelle, formattare dischi o fare reset pesanti di Git. Quando ti serve un comando, puoi consentirlo una volta o sempre.
- Leggere i file a blocchi numerati, fare modifiche mirate, creare file e cercare in tutto il progetto.
- Annullare le modifiche insieme al messaggio della chat che le ha create.
- Portare immagini e documenti dalla chat al progetto senza spostare file a mano.

## Esempi

- "Elenca i file del progetto MomAI e controlla cosa è cambiato in package.json."
- "Correggi l'import rotto in src/index.ts."
- "Esegui i test e dimmi quali sono falliti."
- "Metti l'immagine che ho allegato in src/assets."
- "Lavoriamo nella cartella D:\MioSito."

## Permessi

- **Terminale:** per compilare, eseguire test, usare Git e lanciare script sul tuo computer.
- **File (lettura e scrittura):** per leggere il codice, salvare le modifiche e creare file nei progetti autorizzati.
