# MomAI Code

MomAI Code deja que el asistente trabaje en tu código. Ejecuta comandos en el terminal, lee y edita archivos y se mantiene dentro de la carpeta del proyecto que autorizaste.

## Qué puedes hacer

- Ejecutar comandos dentro de la carpeta del proyecto en Windows (PowerShell o Símbolo del sistema) y en Linux o macOS (Bash).
- Trabajar solo en los proyectos que autorizaste. Sin un proyecto autorizado, MomAI se queda en tu carpeta personal. Si una carpeta aún no está permitida, la pide en el chat.
- Frenar comandos peligrosos, como borrar carpetas completas, formatear discos o hacer un reset fuerte de Git. Cuando necesites uno, puedes permitirlo una vez o siempre.
- Leer archivos por tramos numerados, hacer cambios puntuales, crear archivos y buscar en todo el proyecto.
- Deshacer los cambios junto con el mensaje del chat que los originó.
- Llevar imágenes y documentos del chat a la carpeta del proyecto sin mover archivos a mano.

## Ejemplos

- "Lista los archivos del proyecto MomAI y mira qué cambió en package.json."
- "Corrige el import roto en src/index.ts."
- "Ejecuta las pruebas y dime cuáles fallaron."
- "Pon la imagen que adjunté en src/assets."
- "Trabajemos en la carpeta D:\MiSitio."

## Permisos

- **Terminal:** para compilar, ejecutar pruebas, usar Git y correr scripts en tu computador.
- **Archivos (lectura y escritura):** para leer el código, guardar cambios y crear archivos en los proyectos autorizados.
